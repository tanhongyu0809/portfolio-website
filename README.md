# Tan Hong Yu | Personal Portfolio

Welcome to the source code for my personal portfolio website. This is a highly interactive, futuristic, and premium digital space designed to showcase my journey as a Software Engineering student, my technical projects, and my professional certifications.

## 🚀 Features

- **Futuristic UI/UX:** Built with a modern dark theme, featuring smooth glassmorphism effects, neon gradients, and a pixel-art style aesthetic.
- **3D Interactive Carousel:** A fully custom-built 3D rotational carousel to showcase featured projects, complete with drag-and-swipe controls.
- **Dynamic Micro-Interactions:** Custom cursor tracking, tilt-element 3D effects on hover, and smooth anchor scrolling.
- **Responsive Design:** Completely optimized for both desktop and mobile viewing, ensuring a flawless experience on all devices.
- **Contact Integration:** Direct one-click mailto links configured to bypass local mail apps and open directly into modern web mail composers.

## 🛠️ Technology Stack

- **Structure:** HTML5 (Semantic and accessible)
- **Styling:** Vanilla CSS3 (Advanced grid/flexbox layouts, CSS variables, keyframe animations, 3D transforms)
- **Logic:** Vanilla JavaScript (DOM manipulation, math for 3D coordinate plotting, event listeners)
- **Icons:** Boxicons

## 📁 Repository Note

> **Note:** The `Image/` directory (which contains my personal certificates and awards) is intentionally excluded from this repository via `.gitignore` for privacy and storage optimization.
